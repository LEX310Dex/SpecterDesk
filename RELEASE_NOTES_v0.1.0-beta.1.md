# SpecterDesk 0.1 Beta — First public preview

SpecterDesk is the next-generation evolution of GhostCursor: a private Windows workspace built for presentations, meetings, demos, and focused desktop workflows.

### What ships in this beta

- Cursor-free supported screen sharing while retaining a local replacement pointer
- Capture-excluded private workspace
- Embedded ChatGPT and browser through WebView2
- Private notes
- Silent screenshot to clipboard + local file
- Global hotkeys and system tray controls
- Obsidian dark dashboard and responsive workspace layout

### Tested by the project author

Google Meet, Microsoft Teams, Chrome screen sharing, and Zoom.

### Important

Capture exclusion depends on the Windows capture path used by the receiving application. Treat it as a convenience feature, not a universal security boundary.
